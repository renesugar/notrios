# v0.1 MVP Completion Summary

The v0.1 MVP plan is complete. The repository now contains a local-first notes companion service with REST, a read-only MCP MVP adapter, SQLite canonical storage, a built-in React UI, resource storage, link/backlink graph support, and minimal Joplin RAW / Obsidian importers.

See `MVP_RELEASE_REPORT.md` for release-candidate details and `RELEASE_CHECKLIST.md` before tagging.
